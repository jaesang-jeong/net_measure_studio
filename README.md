# Network Measurement Studio (Rust Edition)
**고성능 분산 타겟 실시간 계측·모니터링 & 제어 시스템**

---

## 1. 개요 (Overview)

**Network Measurement Studio**는 최대 N개의 원격 타겟 계측 장치로부터 수신되는 100+ 채널 고속 계측 데이터(100ms 주기)를 실시간으로 수신·표시·저장 제어하고, 장치 설정 및 저장 파일 회수를 일괄 관리하는 **HOST 기반 계측 모니터링 소프트웨어**입니다.

본 소프트웨어는 성능과 메모리 안전성을 극대화하기 위해 **Rust 언어**로 작성되었으며, 이더넷 MTU(1,500 Bytes)를 초과하는 대규모 채널 데이터 스트리밍에 대비하여 **TCP 스트리밍 옵션(동기화 워드 기반 프레이밍)**을 완벽히 지원합니다.

---

## 2. 주요 기능 및 아키텍처

### 2.1 비동기 3계층 아키텍처 (High-Performance 3-Tier)
1. **네트워크 I/O 계층 (Producer)**:
   * **UDP 수신 엔진 (기본 포트 8000)**: 100ms 주기의 실시간 바이너리 데이터그램 수신 (기본 100채널, 424 Bytes)
   * **TCP 수신 엔진 (기본 포트 8001)**: **MTU 초과 대용량 데이터 전송 옵션**. 바이트 스트림 상에서 Sync Word(`0xAA55`)와 Tail(`0x55AA`), 동적 채널 크기 기반의 스트림 프레이밍 버퍼링을 수행하여 패킷 단편화와 경계 분할을 무손실 복원.
   * Lock-Free / Bounded Queue (`crossbeam-channel`)를 통한 제로 알로케이션 전달.
2. **데이터 프로세싱 계층 (Consumer)**:
   * **CRC-16/CCITT-FALSE** 무결성 검증.
   * 시퀀스 번호 누락 추적을 통한 타겟별 손실률(Packet Loss Rate %) 실시간 계산.
   * 채널별 $Y = aX + b$ (Gain / Offset) 정밀 스케일링 연산 및 임계값(Warning / Alarm) 판정.
   * 고속 시계열 순환 링 버퍼(Ring Buffer)에 적재.
3. **UI 렌더링 계층 (egui / eframe 60 FPS)**:
   * **Min-Max Decimation (다운샘플링)**: 수천 개 이상의 데이터 포인트를 화면 주사율과 픽셀 너비에 최적화하여 렌더링 지연시간 16ms 미만 유지 (GUI 프리징 방지).

### 2.2 UI 및 대시보드 화면 구성
* **한글 글꼴 완벽 지원**:
  * Windows 시스템 한글 폰트(`malgun.ttf` 맑은 고딕 등)를 내장 로더로 자동 바인딩하여 모든 메뉴, 라벨, 테이블의 한글 깨짐 없이 선명하게 표시.
* **고급 그래프 제어 및 오버레이 분석 기능**:
  * **그래프 내부 우측 상단 플롯 범례 (`{이름} [{단위}] ●`)**:
    * 그래프 플롯 캔버스 내부 우측 상단(Right-Top)에 반투명 플로팅 오버레이 범례가 배치됩니다.
    * 측정값이나 스케일 범위 등 불필요한 텍스트를 배제하고, 첨부 그림과 같이 **`채널이름 [단위]`** 텍스트와 오른쪽에 정렬된 **색상 원형 아이콘(`●`)**으로 간결하고 명확하게 표기됩니다.
    * 각 채널 항목 또는 색상 아이콘(`●`)을 클릭하여 해당 플롯 파형을 즉시 감추거나(`○`) 다시 표시할 수 있습니다.
  * **다중 Y축 스케일 오버레이 (Multi-Axis Y-Scale Overlay)**:
    * 서로 다른 단위와 크기(예: 5V, 20A, 80°C, 2500rpm)를 갖는 채널들을 동일한 그래프에 겹쳐서 비교 분석할 수 있도록, 각 채널의 지정 범위를 $0 \sim 100\%$로 정규화 매핑하여 오버레이합니다.
    * 범례(Legend) 및 측정값에는 실제 단위 수치와 채널별 스케일 범위(`[-10~10 V]`, `[0~3000 rpm]`)가 직관적으로 함께 표시됩니다.
    * `[⚙ 채널별 Y스케일 설정]` 팝업 창을 통해 각 채널의 Y-Min / Y-Max를 개별적으로 정밀 지정할 수 있습니다.
  * **X축 시간 길이 지정 (X-Axis Span)**:
    * `5s`, `10s`, `30s`, `60s` 빠른 프리셋 또는 1.0초~300.0초 범위의 드래그 입력을 통해 X축 윈도우 길이를 자유롭게 변경할 수 있습니다.
  * **플롯 영역 좌우 100% 꽉 채우기 (Full-Width Alignment)**:
    * 링 버퍼 용량을 5,000개 샘플(500초 분량)로 대폭 확장하여 `60s`는 물론 최대 `300s`(5분) 윈도우에서도 과거 데이터가 버려지지 않고 완벽 보존됩니다.
    * 최신 수신 시점 기준 `[-window_secs ~ 0.0s]` 상대 시간 윈도우로 매핑하고, 좌측 경계선(-window_secs) 정확한 선형 보간 및 시작 초기 좌측 연장 알고리즘을 적용하여, 그래프의 왼쪽 끝(-60)부터 오른쪽 끝(0)까지 여백 없이 100% 꽉 채워진 전문 오실로스코프/스트립차트 형태로 렌더링됩니다.
  * **Y스케일 사용자 직접 지정**:
    * `Auto-Y` 체크 해제 시 그래프 상단 툴바에서 `Y-Min`, `Y-Max`를 즉시 직접 입력하여 고정할 수 있습니다.
  * **팝업 모달창 맞춤형 크기 제어 (UX 최적화)**:
    * **채널 파라미터 설정창**, **연결 관리**, **SFTP 파일 회수**, **채널 선택**, **Y스케일 설정** 등 모든 팝업 모달 창의 가로(좌우) 크기는 컬럼 내용에 딱 맞게 고정(`min_width == max_width`)됩니다.
    * 세로(상하) 크기는 `resizable([false, true])`가 적용되어 사용자가 창 아래쪽 모서리를 잡고 상하로 원하는 만큼 크게 늘릴 수 있으며, 내부 테이블과 스크롤 영역도 창 높이에 맞춰 100% 동적으로 시원하게 확장됩니다.
  * **영구 저장 (Persistence)**:
    * X축 길이, Y축 범위, 감춘 채널 목록, 다중 Y축 모드 등 모든 그래프 설정이 [`layout_config.json`](file:///C:/agy/net_measure_studio/layout_config.json)에 자동 영구 저장됩니다.
* **우측 채널 리스트 & 실시간 수치창**:
  * 100채널 목록 그리드 (실시간 수치, 단위, 경고/위험 상태별 컬러 배지).
  * 검색 필터 및 경고/위험 필터 지원.
  * 각 채널별 상단 그래프 할당 `[T]`, 하단 그래프 할당 `[B]` 원클릭 토글.
* **10페이지 탭(Page 1 ~ Page 10) 인터페이스**:
  * 하단 10개 고정 페이지 버튼으로 구성.
  * 각 페이지마다 상단/하단 그래프 채널 바인딩 및 레이아웃을 독립적으로 저장·전환.
* **상단 메뉴바 & 제어 기능**:
  * **연결 관리**: 타겟 목록 관리, 통신 프로토콜(UDP / TCP) 전환, 핑 테스트.
  * **채널 설정/동기화**: 채널별 명칭, 단위, Gain, Offset, 임계치 편집 및 타겟 배포(`CMD_CFG_SET`) / 가져오기(`CMD_CFG_GET`).
  * **일괄 저장 제어**: 전체 타겟 대상 동시 녹화 시작(`CMD_REC_START`) 및 중지(`CMD_REC_STOP`).
  * **SFTP 파일 회수**: 타겟 로컬 파일 조회, 백그라운드 다운로드, SHA256 해시 무결성 검증, 타겟 원격 파일 정리(삭제).
  * **내장 타겟 시뮬레이터 (Target Simulator)**: 실제 물리 장비 없이도 원클릭으로 100채널 가상 계측 신호(정현파, 램프파, 노이즈 등)와 TCP 제어 통신을 즉시 검증 가능.
* **하단 상태 표시줄**:
  * 연결 장치 (N/N)
  * 총 패킷 수신률 (%) 및 수신/손실 패킷 수
  * 현재 데이터 통신 프로토콜 (UDP 또는 TCP)
  * 실제 시스템 디스크 여유용량 (GB)
  * 녹화 상태 (대기중 / 녹화중 경과시간)

## 3. 통신 규격

### 3.1 바이너리 데이터 패킷 구조 (Big-Endian, 1-Byte Packing)
| 오프셋 (Byte) | 필드명 | 타입 | 크기 | 설명 |
| :--- | :--- | :---: | :---: | :--- |
| `0x00` | Sync Word | `uint16_t` | 2 | `0xAA55` (패킷 시작 식별자) |
| `0x02` | Device ID | `uint16_t` | 2 | 타겟 장치 번호 (1 ~ 65535) |
| `0x04` | Sequence Number | `uint32_t` | 4 | 패킷 누락 감지용 순차 증가 번호 |
| `0x08` | Timestamp | `uint64_t` | 8 | 계측 시각 (Unix Epoch ms) |
| `0x10` | Status Flags | `uint16_t` | 2 | 센서 연결 상태 및 경고 비트맵 |
| `0x12` | Channel Count | `uint16_t` | 2 | 전송 채널 수 (기본 `100`, MTU 초과 시 가변) |
| `0x14` | Data Payload | `float[N]` | 4*N | N채널 측정값 (기본 100ch = 400 Bytes) |
| `0x14 + 4*N` | CRC-16 | `uint16_t` | 2 | Sync Word부터 Payload까지 CRC-CCITT |
| `0x14 + 4*N + 2` | Tail Word | `uint16_t` | 2 | `0x55AA` (패킷 종료 마커) |

> **MTU 초과 TCP 전송 옵션**:
> 채널 수가 500개(2,024 Bytes), 1000개(4,024 Bytes) 등 일반 이더넷 MTU(1,500 Bytes)를 초과하는 환경에서는 UDP 사용 시 패킷 단편화로 인한 유실이 발생할 수 있습니다. Studio는 TCP 옵션을 활성화하여 스트림 상에서 자동 프레이밍 및 무손실 재조립을 완벽하게 처리합니다.

## 4. 빌드 및 실행 방법

### 요구 사양
* Rust 1.80 이상
* Windows C++ Build Tools (MSVC)

### 빌드 및 테스트
```bash
# 단위 테스트 실행
cargo test

# 애플리케이션 실행 (GUI 모드 - 내장 시뮬레이터 자동 동작)
cargo run --release

# 헤드리스 독립 시뮬레이터만 실행할 경우
cargo run --release -- --simulator-only
```
